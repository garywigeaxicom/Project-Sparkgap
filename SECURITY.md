# Security Policy

Project Sparkgap is currently a documentation-first project and does not provide a production service. Security guidance in [DESIGN.md](DESIGN.md) describes architectural practices, not a guarantee that a deployable implementation has been hardened.

## Reporting a Vulnerability

Do not open a public issue for an undisclosed vulnerability, credential, private dataset, or exploitable configuration. Use the repository host's private vulnerability reporting feature or contact the maintainers through the private channel published for this project.

Include:

- a concise description and affected document or example
- steps to reproduce, when applicable
- potential impact
- a suggested mitigation, if known

Please allow maintainers reasonable time to investigate and coordinate disclosure. Remove secrets from reports and rotate any credential that may have been exposed.

## Scope

Reports may concern unsafe recommendations, accidental sensitive-data exposure, misleading security claims, insecure example configurations, or defects in future reference implementations. General design disagreements belong in public issues or pull requests.

## Supported Versions

Only the latest version on the default branch is actively maintained while the project remains documentation-first.
