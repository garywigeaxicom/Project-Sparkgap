# Reference Implementation v0.1

## Goal

Prove the smallest trustworthy vertical slice of Project Sparkgap: ingest a small, licensed document set, retrieve relevant passages, generate a grounded response, return provenance, and record enough metadata to evaluate the behavior.

## In Scope

- one ingestion command for Markdown or plain-text documents
- deterministic chunking with stable document and chunk identifiers
- one embedding provider and one vector-store adapter
- one model provider behind the inference contract in `docs/api/openapi.yaml`
- `POST /v1/chat/completions` and `GET /v1/health`
- retrieval filters for tenant and sensitivity class
- citations containing document and chunk identifiers
- basic prompt-injection, input-safety, and output-safety checks
- structured request, retrieval, safety, and response events
- automated tests for schema validation, retrieval, API behavior, and refusal paths
- the evaluation cases in `docs/evaluation/fixtures/v0.1-cases.yaml`

## Out of Scope

- production multi-tenancy
- autonomous tool execution or code execution
- model training or fine-tuning
- high-impact decision support
- production secrets, customer data, or proprietary source documents
- Kubernetes, multi-region failover, or GPU autoscaling
- claims of production security or compliance

## Completion Criteria

The slice is complete when a clean environment can run the documented setup, ingest the sample corpus, answer the evaluation cases, return citations for grounded answers, refuse unsupported or unsafe requests, and produce a repeatable test report without using private data or credentials.

## Implementation Order

1. Validate the JSON Schemas and OpenAPI document.
2. Build the ingestion and chunking path.
3. Add the retrieval adapter and provenance response.
4. Add the model adapter and API endpoint.
5. Add safety checks and structured event logging.
6. Add evaluation fixtures and regression tests.
7. Document limitations and observed results before expanding scope.
